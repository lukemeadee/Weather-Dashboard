# Weather Dashboard (Python)
A simple Python weather dashboard that displays weather data using the OpenMeteo API.

## Features
- Overview of most recent update time
- Current location coordinates
- Current weather display (temperature, time)
- Hourly forecast using pandas
- Next 12-hour weather breakdown
- API error handling for reliability

## Technologies Used
- Python
- Requests
- Pandas
- OpenMeteo API

## How to Run
1. Install dependencies:
    pip install requests pandas
2. Run the script:
    python Weatherman.py

## Future Improvements

- Convert city names into coordinates using a geocoding API
